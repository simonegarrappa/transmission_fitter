# transmission_fitter

Welcome to the transmission_fitter GitHub repository!

The code in this repository is presented in Garrappa et al. (2025) A&A 699, A50 (https://doi.org/10.1051/0004-6361/202453440)

Please cite the paper if you use this code in your work.

Create your python environment with e.g. conda to create the environment named 'photcal':

conda crate --name photcal python = 3.13

Activate the environment:

conda activate photcal

To install the package run in the environment:

pip install git+https://github.com/simonegarrappa/transmission_fitter.git

All dependencies will be installed automatically.

To update: 
pip install --force-reinstall --no-deps git+https://github.com/simonegarrappa/transmission_fitter.git@main
